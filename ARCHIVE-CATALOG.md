Этот файл — сохранённая память о выпусках, удалённых из репозитория 01.10.2026 по решению
редакции. Перед версткой нового выпуска с похожей темой — сверяйся с каталогом: стиль, тон,
структура и названия рубрик должны узнаваться как «наши». Полные HTML-коды удалённых страниц
навсегда доступны в git-истории: `git log --diff-filter=D -- <имя.файла>` → `git show <коммит>:<файл>`.

## Формулы стилей (проверены, использовать как базу)
- **Ежедневная газета** — серьёзная типографика (PT Serif + PT Mono + Russo One), полосы, колонки, траурные номера — чёрная рамка/кремовая бумага.
- **Фоторепортаж** — один характер на выпуск: у автосервиса — тёмный гараж + оранжевый неон; у Warlocks MC — кожа/дым; у Four Dragons — неоново-красный Чайна-таун.
- **Статья/интервью** — Playfair + Marck Script (рукописные вставки), большие цитаты-вытяжки.
- **Спецвыпуск (социсследование)** — академическая структура + CSS-диаграммы (donut conic-gradient, bars, stack-лента).
- Общее: самодостаточные страницы (base64 JPEG q80, 1600px), Google Fonts, кнопка-пилюля «← Посмотреть все выпуски редакции» → newsroom.html, титры «Кадры: Anna Malboro · Фоторедактор: Sonya Malboro · Текст/Редактор: Jonny Wilde». RP-чистота обязательна (см. HANDOVER.md §6).
