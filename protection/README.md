Комплект собран по плану «другой ИИ», но переработан под наш репозиторий и наши правила
(HANDOVER §2 «URL вечные», §6 RP-чистота, сборка из `template_*.html`).

## Порядок внедрения (один вечер, ~50 минут)
1. **10 мин** — `LICENSE` в корень + копирайт-комментарий во все `template_*.html` и `newsroom.html`
   (скрипт-вставка приведён в `snippets.md`; в опубликованные выпуски комментарий добавляем
   отдельным решением — см. ниже «ретро-штамповка»).
2. **10 мин** — строка в подвал (шаблон `template_lv_daily.html` и остальные — по списку в `snippets.md`).
3. **10 мин** — штампы: токен `{{STAMP}}` в сборщике + сид-таблица номеров.
4. **10 мин** — вставить блок ритуала в `HANDOVER.md` (§2 и §7).
5. **10 мин** — прогнать `make_release_tags.sh` (dry-run → проверка → apply) и первый `make_manifest.py`.

## Решения, где я сознательно разошёлся с планом коллеги
1. **Лицензия с оговоркой про кадры.** Скриншоты San Andreas — интеллектуальная собственность
   правообладателей игры; заявлять права на них — ослаблять любую жалобу. LICENSE покрывает
   только редакционный слой: вёрстку, CSS, тексты, оригинальную графику, компоновку.
2. **RP-чистота прежде всего.** Ни слова «лицензия», «CC», «DMCA», «copyright» в видимом тексте
   страниц. Всё юридическое — только в HTML-комментариях и в файле LICENSE. Видимая строка в
   подвале формулируется внутриигровым языком: «дизайн и вёрстка — редакция San Fierro News».
3. **Ретро-штамповка опубликованных страниц — отдельное решение, не дефолт.** URLs вечные,
   правки только содержимым; комментарий не меняет вид, но меняет байты 28 файлов.
   Дефолт: штампуем шаблоны + хаб + все будущие выпуски. Ретро — скриптом, одним коммитом,
   когда скажешь «ретро-штампуй».
4. **Реестр фирменных классов вместо запрета рефакторить.** «Никогда не упрощайте имена
   классов» — плохой абсолютный совет: рефакторы будут. Вместо этого в `snippets.md` ведём
   реестр сигнатурных имён; форензика переживает любой рефактор, потому что мы сами
   документируем, какие имена считать отпечатком.
5. **Снапшоты archive.org — и наших страниц тоже.** План коллеги фиксировал только страницу
   вора. Наша собственная датированная копия на независимом сервисе сильнее любой истории
   коммитов: её нельзя «перепутать с форком».
6. **Ожидания от DMCA — реалистичные.** DMCA на GitHub сносит явную копию файлов/кода.
   «Похожий стиль» без наших маркеров — не DMCA-кейс, а кейс администрации сервера.
   Поэтому маркеры и манифест важнее лицензии: они переводят «похоже» в «совпадает побайтово/
   по отпечаткам».

## Чего в плане коллеги не было и что добавлено здесь
- хэш-манифест выпуска (`make_manifest.py`) — доказательство «файл X с хэшем Y существовал на теге Z»;
- сид-таблица номеров штампов 001–028 (иначе нумерацию придётся выдумывать постфактум);
- само-архивирование наших страниц на web.archive.org;
- оговорка про игровые кадры в LICENSE;
- ограничение: archive.org не снимет страницу форума под логином — там работаем
  скриншотом + сохранённым исходником + хэшем (процедура в `evidence-and-complaints.md`).

## Важно про публикацию из этой песочницы
У меня здесь сознательно нет никаких креденшалов (токен ты присылал в чат — он отозван/должен
быть отозван; SSH-ключа в этой песочнице нет). Поэтому комплект я подготовил файлами, а
применяется он в твоей обычной песочнице редакции, где настроен SSH:
`git add protection LICENSE && git commit && git push` — или отдай команду мне в следующей
сессии с SSH-бутстрапом, внесу всё сам по этому комплекту.
