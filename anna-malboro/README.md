# `anna-malboro/` — стол редактора Anna Malboro · газеты, ожидающие подшивки

Памятка для генерального директора.

## Суть папки

Здесь лежат **готовые газеты редакции Anna Malboro**, которые ожидают подшивки на основной
сайт (корень репозитория + хаб `newsroom.html`). Каждая газета — самодостаточный `.html`:
изображения вшиты base64, шрифты — Google Fonts, внешних скриптов нет. Открывается в любом
браузере, в том числе без скачивания:

```
https://htmlpreview.github.io/?https://github.com/Wereskkk/San-Fierro-News-Evolve-RP/blob/main/anna-malboro/<имя-файла>.html
```

Папка — **очередь, а не архив**. Архив — корень репозитория и хаб. Всё, что было
опубликовано до 03.10.2026, уже лежит в корне; через эту папку идут только новые поставки.

## Порядок подшивки (что делает генеральный директор)

1. **Перенести файл в корень без изменения имени**:
   `git mv anna-malboro/<имя>.html <имя>.html`.
   Имя файла = вечный URL; переименовывать нельзя (принцип «URL вечные», HANDOVER §2).
2. **Вшить карточку в хаб `newsroom.html`** по правилам HANDOVER §4: badge типа выпуска,
   stripe-цвет, cardmeta (дата, город), заголовок, описание, ссылка «Читать выпуск»;
   строка даты сверху, у прежней верхней строки снять пометку «· свежий номер».
   Если рядом с газетой лежит файл `<имя>.card.txt` — это **готовый HTML карточки**:
   вставить в хаб как есть (дату/статистику всё равно проверить).
3. **Обновить статистику хаба**: `+1 выпуск` и `+N кадров` (N — число вхождений
   `data:image/jpeg;base64` в файле газеты).
4. **Удалить газету из этой папки тем же коммитом** (или следующим сразу):
   подшитая газета из `anna-malboro/` пропадает — в папке остаётся только то, что ещё не
   на основном сайте.
5. Ритуал опечатывания (по желанию, как для остальных выпусков): тег `v-<имя-без-.html>`
   на первый коммит файла, `python3 protection/scripts/make_manifest.py` → коммит
   `manifest.json`, анонс на форуме/Discord в день выхода, снапшот на web.archive.org.

Содержимое газет при подшивке **не правится** — они проходят RP-вычитку и guard G4/G5/G6
до загрузки; подшивка байт-в-байт.

## Границы ответственности (почему не будет конфликтов)

- Редакция Anna Malboro пишет **только в `anna-malboro/`** и не трогает корень,
  `newsroom.html`, шаблоны и скрипты.
- Корень и хаб — зона генерального директора; подшивку делает он (или даёт явную команду).
- Стороны правят непересекающиеся файлы → слияния проходят автоматически, merge-конфликты
  исключены. Пуш только fast-forward, force-push запрещён у обеих сторон.

## Техническое (для будущих редакторов)

- Папка **исключена из guard G1**: исчезновение файла из `anna-malboro/` — не нарушение
  (это штатный результат подшивки). Из корня файлы по-прежнему не удаляются никогда.
- Папка **исключена из тегов** (`make_release_tags.sh`) и **не входит в `manifest.json`**
  (манифест — реестр опубликованных страниц корня).
- Загруженные газеты тем не менее проходят guard G4 (RP-чистота), G5 (base64) и
  G6 (title/viewport) — качество контролируется до подшивки.
